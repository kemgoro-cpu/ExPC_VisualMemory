# External PC Visual Memory 0.2.2 — 初回起動

## 1. 起動

`visual-memory\visual-memory.exe`を実行します。ローカルUIは先に開き、OCRと意味検索モデルはバックグラウンドで準備されます。黄色い「準備中」表示が消えるまで、記録開始ボタンは無効です。

## 2. 映像入力

キャプチャーボードを接続し、「デバイスを再検出」から映像入力を選択します。一度選んだ入力は次回起動時も記憶されます。

## 3. 記録と検索

「記録を開始」で画面履歴を保存します。検索欄ではOCR文字検索と意味検索を併用できます。「さらに読み込む」で過去の候補を追加表示できます。

自動記録は画面の変化と静止を手がかりに代表的な画面を残します。「この画面を保存」は画像・サムネイル・保存情報が書き込まれた後に「保存済み」を表示します。「保存中」は未完了です。処理が遅い場合は結果確認を続けられます。保存数は候補数とは別に表示します。

OCRが利用できない間も画像は保存します。画面ごとのOCR状態で、未処理・利用不可・再試行・失敗を確認できます。OCRが復旧すると待機中の画面を処理します。繰り返し失敗した画面は、詳細から再処理してください。旧版で空文字だけが残り処理成否が分からない画面は、自動で成功扱いや一括再処理をしません。

短い検索語も含め、複数語の文字検索は「いずれかに一致」です。検索候補には文字検索・意味検索それぞれ最大200件の上限があります。「表示中のN枚を選択」は、まだ読み込んでいない画面を含みません。

## 4. AIへ渡す文書

必要な画面だけを選択し、右側のバスケットからコンテキスト文書を作成します。生の画面履歴はMCPへ公開されません。作成済み文書は24時間後に既定で期限切れになります。

作成完了と同時にMCP共有が始まります。24時間はAIから取得できる期限で、保存期限ではありません。期限切れ・共有停止後も文書はローカルで閲覧・保存できます。

PDFに全文を含める場合は「PDFにOCR全文を付ける」を有効にしてください（既定OFF）。OFFでは画像と重要OCRを中心にした文書です。ONでもOCRが読み取れなかった文字は含まれません。PDF生成中は進捗状態を表示し、失敗時は同じ文書で再試行できます。

文書詳細で重複除去とOCR全文の設定を変更し、同じ文書を再生成できます。選択順と共有状態・期限を引き継ぎます。旧文書も元画像が残っていれば再生成できます。画像の拡大とページ削除の選択は別操作です。

通常の画面履歴は30日で自動削除されますが、文書に使った元画像と文書は長期保持します。容量表示で通常履歴・長期保持画像・文書を確認してください。文書を削除しても元画像は長期保持を継続します。別文書に使われている画像を履歴削除で消すことはできません。容量不足時は新規保存が失敗し、長期保持画像が自動削除されることはありません。

## 5. セキュリティ

画面履歴はローカルに保存されます。APIはローカルホスト限定で、ランダムトークンとCSRFトークンにより保護されます。

## 配布プロファイル

- `lite`: OCR・意味検索モデルを含まない小容量版。画像保存と手動選択を確認する用途です。
- `full`: PaddleOCR、多言語E5、モデルを同梱した完全オフライン版です。
